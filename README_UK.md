# VOXEL GROVE 0.2.0 — власна 3D-пісочниця для Android

Автор: waserko. Підготовлено на базі попередньої **Voxel Grove 0.1.0** з тим самим applicationId `ua.waserko.voxelgrove`.

**Це вихідний проєкт Android Studio, а не готовий APK.** Збірка Android 0.2 у поточному середовищі не запускалася через відсутність Android SDK/Gradle; Java-логіку та синтаксис Android-класів перевірено окремо. APK можна зібрати в GitHub Actions або Android Studio за інструкцією нижче.

## Що нового порівняно з 0.1

- 27 типів блоків: трава, земля, камінь, дерево, листя, пісок, цегла, кристал, вода, вугілля, залізо, мідь, золото, алмази, гравій, дошки, скло, пісковик, сніг, кактус, верстак, піч, корінна порода, глина, обсидіан, мох, сапфірова руда.
- Унікальний піксельний атлас текстур `app/src/main/assets/terrain.png` (128 × 64, піксель-арт 16 × 16).
- Гори, три типи місцевості, малі печери, рудні поклади, дерева, кактуси, плями води.
- Дві структури: дерев'яна хатина й кам'яні руїни.
- Прості істоти: вівці, кабани, тіньові створіння. Вони повільно пересуваються, останні завдають шкоди поблизу в режимі виживання. Це базові спрощені 3D-фігури, **не повноцінні моби з Minecraft**.
- Два режими: творчий із необмеженими блоками; виживання з ресурсами, здоров'ям, ситістю, їжею, руйнуванням і будівництвом із запасів.
- Меню **Сумка** з вибором одного з 27 блоків, налаштуванням 8 слотів панелі.
- **12 простих рецептів**: дошки, палиці, верстак, піч, цегла, скло, смажене м'ясо, злитки металів, пісковик, кристал.
- Сенсорні кнопки: біг/хід, камера, стрибок, встановити/зламати блок, удар, їжа, крафт, інвентар, пауза.
- Синьо-зелений денний та темний нічний небосхил із циклом ~5 хвилин.
- Рендер кубів із перебудовою мешу лише змінених 16×16 ділянок. Світ лишається 48×28×48 блоків.
- Версіоновані сейви. Збереження старої 0.1 `.vg` читаються новою грою. Новий формат запам'ятовує інвентар, режим, мобів і день.

## Керування

Грати / Продовжити — відкриває останній світ; новий світ — замінює старий. Вибір **Виживання** / **Творчість** у стартовому меню перемикає режим. У грі: джойстик зліва; праворуч пальцем повертай камеру; стрілка ↑ — стрибок; `−` прибирає блок; `+` ставить вибраний; `⚔` — удар по найближчій істоті перед гравцем; `Їжа` — з'їсти запас їжі; `Сумка` — вибір матеріалу; `Крафт` — рецепт. Більшість рецептів у виживанні вимагає ресурсів; у творчому режимі безкоштовні.

Гра офлайн, не запитує дозволів. Світ зберігається у приватних даних застосунку кожні 15 секунд і при виході/паузі. **Перед перевстановленням або видаленням застосунку зроби резервну копію даних через дозволений системний механізм, інакше прогрес буде втрачено** (Android Backup вимкнено).

## Збирання APK з телефону через GitHub

1. Створи GitHub-репозиторій `VoxelGrove` (приватний або публічний).
2. Розпакуй ZIP цього проєкту. Завантаж в репозиторій **вміст папки `VoxelGrove`**, не сам ZIP. Важливо зберегти каталоги `app/`, `gradle/`, `.github/` та `gradlew`.
3. Відкрий GitHub → репозиторій → **Actions** → **Build Android** → **Run workflow**. Або зроби commit у гілку `main`.
4. Після успішної збірки у результаті запуску відкрий **Artifacts** → `VoxelGrove-Android` → завантаж архів.
5. Розпакуй і встанови `app-debug.apk` на свій Android. Це **debug-версія для тестування**, не реліз Google Play.
6. Якщо збірка не пройшла, збережи логи із вкладки Actions і використай їх для виправлення.

У GitHub Actions використовуються Java 17, Android SDK 36, Gradle Wrapper 8.11.1, Android Gradle Plugin 8.10.1; спочатку запускаються тести `WorldTest`.

## Збірка у Android Studio

Відкрий папку `VoxelGrove` як проєкт, встанови JDK17, Android SDK Platform36 + Build Tools36, дочекайся Gradle Sync. **Build → Build APK(s)** або команда `./gradlew assembleDebug`. Результат — `app/build/outputs/apk/debug/app-debug.apk`.

Щоб опублікувати в Google Play, потрібен окремий **підписаний релізний AAB**, іконка/скриншоти власної гри, політика конфіденційності, перевірка на реальних пристроях і виконання правил Play Console. Не використовуй debug APK як магазинний реліз. Досягнення 18 років потрібне для власного облікового запису видавця Play Console; до того справжнім власником акаунта має бути дорослий.

## Перевірки

Без Android SDK, але з JDK:

```bash
mkdir -p test-out
javac -d test-out app/src/main/java/ua/waserko/voxelgrove/World.java tests/WorldTest.java
java -cp test-out ua.waserko.voxelgrove.WorldTest
```

Перевірено 25 тестів алгоритмів: стабільна генерація, руда, структури, фізика, взаємодія, вода, крафт, їжа, інвентар, запис/читання, старий формат сейвів. Для Android UI виконано лише пробну компіляцію синтаксису зі спеціально створеними заглушками API, а **не** справжній Android-білд чи запуск на телефоні.

## Чого поки немає

- Повного набору ресурсів, механік, мобів, інструментів, біомів, структур, ферм і вимірів Minecraft Java 1.16.5.
- Анімацій персонажів, складного ШІ, генерації нескінченного світу, справжньої фізики води/лави, освітлення факелів, мультіплеєра, звуку, збереження багатьох світів.
- Повного бойового циклу та смерті/відродження. Наразі HP не падає нижче 1.
- Перевіреної роботи на справжньому Android-пристрої, тестів fps/стабільності або готового release-пакета.

У майбутніх версіях можна додати чанкове генерування безкінечного світу, професійні текстури, оптимізовані колізії, повний крафт і поведінку істот. Усі назви/текстури/графіку робимо власними для незалежної гри, а не включаємо чужі матеріали.

- `app/src/main/java/ua/waserko/voxelgrove/World.java` — блоки, світ, фізика, ресурси, crafting, моби, збереження.
